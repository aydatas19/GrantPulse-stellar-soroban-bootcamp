# Level 5 Growth And Retention Strategy

GrantPulse Level 5 moves from MVP validation to repeatable onboarding. The strategy is to make each tester produce three signals: a connected wallet, a real Testnet transaction, and useful product feedback.

## Acquisition

| Channel | Audience | Message |
| --- | --- | --- |
| Bootcamp peers | Builders learning Soroban | Test a wallet-backed grant workflow and submit proof |
| Hackathon groups | Founders and demo-day teams | Track milestones with public transaction evidence |
| Reviewer mentors | Ecosystem reviewers | Try the approve/reject flow and flag trust gaps |
| Stellar communities | Testnet users | Help validate a transparent microgrant dashboard |

## Activation

Activation is counted when a tester completes all of these:

1. Connects Freighter on Stellar Testnet.
2. Completes at least one wallet-backed action in GrantPulse.
3. Submits the Google Form with wallet address, email, rating, feedback, and transaction proof.

## Retention Hooks

| Hook | Purpose |
| --- | --- |
| Grant verification card | Gives builders a shareable progress state |
| Reviewer counts | Makes feedback from mentors visible |
| Evidence export | Helps teams prepare demo-day or grant reporting packages |
| Feedback iteration summary | Shows testers that their feedback changed the product |

## Next Growth Experiments

- Add a public read-only grant gallery so testers can inspect projects without connecting first.
- Add copy-to-clipboard buttons for grant IDs, wallet addresses, and transaction hashes.
- Add a review invite link that pre-fills owner address and grant ID.
- Add a post-demo email template that asks testers for one more review after an update.
