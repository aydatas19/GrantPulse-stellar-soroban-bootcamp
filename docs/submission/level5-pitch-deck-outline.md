# Level 5 Pitch Deck Outline

The PowerPoint file lives at `docs/pitch/grantpulse-level5-pitch-deck.pptx`. Use this outline to verify that the deck covers every Level 5 presentation requirement before recording the final walkthrough.

## Slide Checklist

| Slide | Required Message |
| --- | --- |
| 1. GrantPulse | Product name, Stellar Soroban positioning, live demo link |
| 2. Problem | Small grant programs need public progress proof, reviewer signals, and auditable activity |
| 3. Solution | Wallet-connected grant records, milestones, reviewer actions, and evidence exports |
| 4. User Flow | Connect wallet, fund Testnet, send transaction, create grant, review, submit feedback |
| 5. Architecture | React, Freighter, Stellar SDK, Soroban contract, Horizon Testnet, Stellar Expert |
| 6. Traction | 50-user target, valid wallets, transaction proofs, ratings, top feedback themes |
| 7. Growth Strategy | Builder cohorts, reviewer loops, demo-day sharing, feedback-driven onboarding |
| 8. Roadmap | Feedback analysis, onboarding improvements, proof verification, richer grant discovery |
| 9. Ask | Ecosystem feedback, demo opportunities, pilot users, grant program partners |
