# GrantPulse Level 5 Demo Script

Use this flow for the Level 5 walkthrough recording.

## Recording Outline

1. Open the live app.
   - Show the GitHub Pages URL.
   - Show the deployed contract and Stellar Expert links from the header.

2. Connect Freighter on Stellar Testnet.
   - Show wallet connection.
   - Show XLM balance.
   - Fund with Friendbot only if needed.

3. Send a real Testnet XLM transaction.
   - Enter a recipient Testnet public key.
   - Send XLM.
   - Open the Stellar Expert transaction hash.

4. Create and update a grant.
   - Create a grant record.
   - Complete one milestone.
   - Refresh the grant verification card.

5. Review the grant.
   - Use a reviewer wallet if available.
   - Approve or reject once.
   - Show the updated approval or rejection count.

6. Submit Level 5 feedback.
   - Enter name, email, wallet address, rating, feedback, blocker, and transaction hash.
   - Submit feedback.
   - Export CSV and JSON evidence.

7. Show Level 5 growth proof.
   - Show test user count.
   - Show transaction proof count.
   - Show active usage events.
   - Show average rating and latest telemetry.

8. Close with submission assets.
   - README Level 5 section.
   - Excel feedback export link.
   - Pitch deck link.
   - Demo video link.

## Final Video Checklist

- The wallet is visibly on Stellar Testnet.
- At least one real transaction hash is shown.
- The app flow is shown end to end.
- The Level 5 dashboard is visible.
- The README submission section is visible.
- The final exported user proof file is mentioned.
